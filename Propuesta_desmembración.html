04 Desmembraciones

Esta sección usa como base el polígono calculado en la sección 02. Seleccioná “Sí” para activar el modo gráfico y elegí dos o tres puntos para definir la desmembración: A y B sobre el perímetro y, opcionalmente, C dentro del polígono.

Cómo usarlo: marcá A y B sobre el perímetro. El punto C es opcional: si lo agregás, debe quedar dentro del polígono. Después podés arrastrar los puntos para ajustar la porción. El punto C no necesita tocar ningún lindero. Si preferís, podés ingresar manualmente el área que querés desmembrar; en ese caso el área ingresada será la que se utilizará para el cálculo y el PDF.

Modo recorrido: seleccioná A, B y C como hasta ahora.
